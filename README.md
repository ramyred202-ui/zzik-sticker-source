# 찍스티커 (ZzikSticker)

오늘의 사진을 AI로 오려 나만의 스티커로 만들고, 하루 한 페이지의 다이어리에 붙여 추억으로 간직하는 모바일 PWA입니다. 만든 스티커는 스티커북에 모으고 냉장고/화이트보드/현관문/파티션 보드에 붙이거나, 가챠처럼 쏟아 즐길 수도 있습니다.

서버나 백엔드 없이 순수 HTML/CSS/JS로만 동작하는 클라이언트 전용 앱이며, 저장은 브라우저의 IndexedDB를 사용합니다.

## 폴더 구성

- `index.html` — 앱의 기본 뼈대
- `app.js` — 전체 로직 (오늘 홈, 다이어리, 카메라, 배경 제거, 스티커북, 보드, 가챠 등)
- `style.css` — 전체 스타일
- `service-worker.js` — PWA 오프라인 캐시
- `manifest.json` — PWA 설치 매니페스트
- `icons/` — 앱 아이콘
- `PRODUCT_PLAN.md` — 현재 제품 분석과 기능 개선 기획
- `UI_UX_REDESIGN_PLAN.md` — 추억 다이어리 중심 UI/UX 개편안과 화면 배치도

## 주요 기능

- 오늘의 무드와 한 줄 질문으로 날짜별 다이어리 작성
- 선택한 무드에 어울리는 감성 스티커 추천
- 데일리·포토·감사·학교·여행·무드 다이어리 템플릿
- 제목, 글, 사진, 배경 테마, 내 스티커로 페이지 꾸미기
- 작성 중인 다이어리를 IndexedDB에 자동 저장
- 책 페이지를 넘기듯 저장한 추억을 읽고 다시 꾸미기
- 다이어리/달력 전환과 월간 대표 무드 확인
- 사진 촬영/선택 후 기기 안에서 AI 배경 제거
- 만든 스티커를 다이어리에 바로 붙이거나 스티커북에 보관
- 스티커 보드 배치, 꾸미기, 가챠 물리 효과
- 앱 전체 감성 테마 선택

## 테스트/배포 방법

지금은 별도 빌드 과정이 없습니다. `index.html`을 정적 파일 호스팅(Netlify Drop 등)에 올리면 바로 동작합니다.

배포한 뒤 화면 상단의 빌드 배지(`build-YYYY-MM-DD-NN` 형식, `app.js` 상단의 `BUILD_ID`)로 최신 버전이 반영됐는지 확인할 수 있습니다.

## 함께 작업하기

이 저장소를 각자 로컬에 내려받아 수정한 뒤, GitHub Desktop이나 `git push`로 반영해주세요. 코드를 수정한 뒤에는 `app.js`의 `BUILD_ID`와 `service-worker.js`의 캐시 버전(`SHELL_CACHE`/`RUNTIME_CACHE`)을 함께 올려주시면, 배포 후 실제로 새 버전이 적용됐는지 배지로 바로 확인할 수 있습니다.
